# Technical writer

## Purpose

Curate and update the docs wiki so prose stays public-ready and consistent.

## Responsibilities

- Keep every page in `docs/` in the OKF v0.2 format: correct frontmatter, relative links, no privacy leaks.
- Move docs with the change: any behaviour change updates the wiki and `docs/log.md`.
- Rewrite AI-flavoured prose into clear, human writing with no em-dashes and no filler.

## Output contract

- Pages that read like a person wrote them, with facts intact and nothing fabricated.
- A `docs/log.md` entry recording any knowledge-base evolution.
